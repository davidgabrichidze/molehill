# Molehill original assets

These are individually authored vector assets, not crops from a presentation board. SVGs are the source files; PNGs are rendered from those SVGs at high resolution.

- `svg/logos`: standalone marks and wordmarks
- `svg/icons`: rounded-square application icons in multiple color states
- `svg/hero`: GitHub README hero illustration showing one Molehill client connecting to multiple VPN networks
- `png/`: matching PNG exports (logos at 2x+ scale, icons 1024×1024, hero 4800×2240)

The logo stays deliberately minimal: layered hill/tunnel arches, eyes, and a small coral nose. VPN-provider routes are shown in the hero illustration, not added to the core mark.
